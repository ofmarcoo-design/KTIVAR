# Inter — distribuição local

Inter Variable 4.1, arquivo original sem alterações.

Fonte: https://github.com/rsms/inter/tree/v4.1/docs/font-files
Download: https://raw.githubusercontent.com/rsms/inter/v4.1/docs/font-files/InterVariable.woff2
Licença SIL Open Font License 1.1: LICENSE.txt, redistribuída junto do arquivo.

O CSS expõe somente os pesos aprovados 400–700; `font-display: swap` preserva
leitura durante carregamento. WOFF2 servido pelo próprio Express, sem CDN ou
requisição a serviços de fontes. A família suporta português brasileiro,
numerais tabulares e zero cortado. Não é necessário instalar nova dependência.
